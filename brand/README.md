# Brand-Dateien von Kliqtape

Logo, Icon und Farbvarianten von Kliqtape.

**Diese Dateien stehen nicht unter der AGPL-3.0.** Alle Rechte vorbehalten.
Was erlaubt ist und was nicht, steht in [`TRADEMARKS.md`](../TRADEMARKS.md).

Wer einen eigenen Server mit der offiziellen App betreibt, braucht diese Dateien nicht. Wer
einen Fork mit eigener App baut, entfernt diesen Ordner und verwendet einen eigenen Namen und
ein eigenes Logo.

## Inhalt

| Ordner | Was |
| --- | --- |
| `logo/` | Wortmarke hell, dunkel und mit App-Hintergrund (SVG + PNG 4000 px), Icon (SVG + PNG 1024 px) |
| `varianten/<kassette>/` | Sondervarianten der sechs Standard-Kassetten: Amber, Ice, Atomic Purple, Tabak, Kiwi, Berry |

Die Wortmarke ist in Archivo Bold (Breite 75 %) gesetzt und in Pfade umgewandelt, sie braucht
also keine installierte Schrift. Archivo und Caveat stehen unter der SIL Open Font License.
